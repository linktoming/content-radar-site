🔭 今日主线

今天的主线不是“又一个模型发布”，而是 agent 从 demo 进入生产之后，系统开始暴露真正的约束：长任务安全、可验证执行环境、算力供给、开放模型、以及 founder 自己的内容系统。

源头层里，OpenAI 和 Anthropic 都在讲 long-horizon / autonomous agents 的风险；Perplexity 把问题落到 SPACE 这种可暂停、可恢复、可销毁的运行时；Cursor 用 agent swarm 重建 SQLite，证明多 agent 协同已经可以被成本化、评测化。

外部答案卷也对齐：TLDR AI 把 Qwen 3.8、Kimi Code CLI、Netflix LLM stack 放在头条；AINews 连续几期指向 Kimi / Inkling / open-weight 模型。真正的变化是：闭源 frontier 仍在定安全边界，开源/开放权重正在逼近可用性，基础设施公司开始抢“agent 时代的操作系统”位置。
