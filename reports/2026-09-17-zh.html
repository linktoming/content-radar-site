🔭 今日主线

Agent 栈进入可运营期：前沿实验室在补治理、语音入口与真实场景责任，基础设施在把 agentic inference 变成可计量的生产能力，国内内容平台则把 AI 编程、AI 视频、AI 工作流包装成普通人能立刻复用的生产系统。

今日 News 与 Viral 两份日报合并后，最强信号是同一条链路的上下游同时变硬：上游的 Google DeepMind Institute、Gemini 3.8 Live、OpenAI 老年人 AI 使用项目、Anthropic 威胁情报 都在往真实人群、真实工作流、真实责任走；中游的 NVIDIA/AMD/Lambda/CoreWeave/Nebius 正在用 MLPerf、能耗、KV cache、agentic workload 讲清楚推理成本；下游的 Muse、OpenClaw、OmniAgent、DataFast MCP/API 则把入口从聊天框推向工作台。

对创作者和一人公司来说，今天真正值得写的不是“哪个模型更强”，而是：如何把模型、内容、知识库、工具调用、版本管理和人类判断装成一套可运营系统。Viral 侧也印证这一点：B 站、小红书、抖音的高热内容集中在 Codex、Claude Code、Pi、豆包 Agent、AI 视频、Obsidian/NotebookLM 知识库、AI 一人公司——大众需求不是理解参数，而是把 AI 变成能马上交付的工作流。

🎯 News · 源头与基础设施

Frontier labs / model makers

  • Google DeepMind 发布 Gemini 3.8 Live 和 3.8 Live Extended Thinking，重点是实时语音、后台思考、不中断任务 flow。
  • Demis Hassabis 与 Shane Legg 推出 DeepMind Institute，把 AGI 的经济、科学与社会影响制度化研究；这与 Dario Amodei、Sam Altman、Naval 关于 frontier pacing / liability 的讨论形成治理主线。
  • OpenAI 写“帮助老年人在日常生活中使用 AI”，另有 AI 广告重构、Fyxer AI executive assistant 案例，说明 AI 正在进入具体行业工作流。
  • OpenAI 披露用最新 cyber models 动员 250+ 人强化内部系统防御；Anthropic 发布威胁情报报告，覆盖 Claude 被滥用于网络攻击、影响行动、监控、生物和武器构建的尝试。
  • Mistral AI 与 Mozilla 合作，把隐私、控制和选择带进 AI 浏览器。
  • MiniMax H3 上线 Together AI：33B omni-modal video model，支持 4–15 秒、最高 2K、原生立体声，以及文本、图像、视频、音频上下文。
  • DeepSeek V4.1-Flash 出现在 Hugging Face 趋势池；中文侧 B 站也在讨论 DeepSeek V4.1 Flash 与 Seed 2.1 Pro 的成本/能力对比。

Infra / inference

  • NVIDIA Vera Rubin NVL72 在 MLPerf Inference v6.1 首秀；SemiAnalysis 给出的读法是：Vera Rubin NVL72 在 170 tokens/s SLO 下约有 67x GB300 throughput per dollar。
  • AMD 称在 512-GPU scale 创下 5.75M tokens/sec MLPerf 记录；SemiAnalysis 也说 AMD MI355X 正在缩小 agentic inference 的 perf/TCO 差距。
  • Lambda 强调 MLPerf v6.1 首次出现 datacenter hardware 上的 agentic inference workload；Nebius 报告 DeepSeek R1 603,023 tokens/sec；CoreWeave 用 Blackwell Ultra 讲性能领先。
  • Fireworks AI 给出 agent 成本结构：DeepSWE on Astra vs DeepSeek V4.1-Flash 中 input tokens 是 output 的 174:1，99.6% 是 cache hits，而 cache hits 占账单 60%。关键不只是输出 token 价格，而是上下文复用与 cache 计费。
  • Perplexity 披露 CobbleDB：两名工程师和数百个 always-on AI agents 构建 key-value database，并计划开源。

Dev tools / harness

  • OpenClaw v2026.9.4 发布插件/skill、旧聊天转 skill、GPT Image 2.5 canvas、云控制、终端内回复等功能。
  • OpenClaw 与 Hugging Face、NVIDIAAI、AntLingAGI 做本地 AI assistant session，主题是 Ling-3.0-flash + DGX Spark。
  • OmniAgent 展示开源 meta-harness 同时跑 Claude Code 和 Codex；Omnigent v0.14.0 加了 multi-repo GitHub PRs/sandboxes、composer redesign、Claude/Codex workflow。
  • LangChain 把 Deep Agents 的核心挑战定义为 context engineering；Managed Deep Agent 作为 MCP server 暴露。
  • Warp 内置 Grok Build CLI；Replit 推 Free Mode；Vercel 用 Delphi 案例讲 10 人团队无专职 infra 也能跑 long-running agents、background jobs、100+ production workloads。
