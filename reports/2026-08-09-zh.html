🔭 今日主线

Agent 开始从“会干活”进入“要被治理、可迁移、能计价”的阶段。今日扫描 298 个追踪实体 · 24 个 fetcher/lane · 1472 条原始信号；最强的一条线不是单点模型升级，而是 OpenAI 把 Astra 按 critical cyber 能力处理、Vercel/Cursor 推 Agent Plugins、Claude Code 准备默认 Auto mode、Sierra 把 voice/persona/context 拆成企业 agent 的可控层。

这说明下一阶段的竞争核心变了：模型能力继续涨，但真正拉开差距的是“谁能把 agent 放进真实工作流以后，还能解释权限、记忆、上下文、安全与成本”。对内容创业者也是同一个问题：不是会不会用 ChatGPT，而是能不能把 Codex/Claude Code/Cursor 这类工具变成可复用的内容生产系统。

🎯 源头 · Primary

📦 本日发布
- OpenClaw v2026.6.33 — 今日稳定基线继续进报告；这类 harness release 是“agent 操作系统”层的基础设施信号。

模型 / 安全
- OpenAI — 把 upcoming model Astra 作为首个 cyber “critical” 模型处理，并暂停未满足强化安全要求的相关内部活动；Sam Altman 同步强调不是保留给少数人，而是需要更安全地开放。
- OpenAI — 改进 GPT-5.6 Sol，并扩大 GPT-5.6 Luna 免费使用；OpenAI X 明确 Chat 版 Sol 更新不影响 Work/Codex 里的版本。
- Anthropic / Claude — 调整 Fable 5 生物安全 fallback，称测试中相关误拒下降约 85%；这是一条“能力提升后，安全阈值也要更细”的源头信号。
- Mistral — 发布 Shieldstral 3B open-weights moderation model，用自然语言 policy 做文本/图像安全判断，适合本地或私有部署的内容安全层。

Agent / 工具协议
- Vercel 与 Cursor — 推出 Agent Plugins 1.0.0，把 Agent Skills 与 MCP server 打成可分发插件，合作方包括 AWS、Codex、Cursor、GitHub、OpenAI Developers。
- Boris Cherny / Claude Code — 说多层防护可以把 indirect prompt injection 在 unseen attacks 上压到接近 0；Auto mode 将用单独 classifier 审查 shell/action，下周成为默认 permission mode。
- Omnigent — 展示 Polly 多 agent 编排：Claude Code、Codex、Pi 等共享 session、policy、sandbox 与成本模型。这个方向和 OpenClaw 的“多会话/多 agent 操作层”同频。
- Sierra — Context Engine 把企业知识转成 agent 可持续决策的上下文；Voice Personas 让 voice agent 同时有声音与品牌人格，并声称 resolution rate 最高提升近 50%。

开放模型 / 视频
- Kimi — Kimi Work 开始把 K3 用在 slides 生成；生态侧 Fireworks 和 Nebius 都在围绕 Kimi K3 做成本/部署叙事。
- Together — DeepSeek V4 Flash + test-suite verification 在 DeepSWE 上比 Luna 单跑更便宜且解题更多，说明“模型 cascade + 验证 harness”正在取代单模型崇拜。
- Runway / Pika — Seedance 2.5 进入视频创作工具链，主打 30 秒、有声、多人/多 reference 的连续世界生成。
- Google DeepMind WeatherNext — AI cyclone forecasting 成为专业热榜与机器之心共同信号，属于 AI 进入高价值科学/公共安全场景的硬进展。
