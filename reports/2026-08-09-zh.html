Agent 栈进入“可控基础设施”阶段：OpenAI 一边把 GPT-5.6 Luna 下放给免费用户

🔭 今日主线

Agent 栈进入“可控基础设施”阶段：OpenAI 一边把 GPT-5.6 Luna 下放给免费用户，一边把 Astra 按 critical cyber 能力加闸；Anthropic 同时在 Fable 5 上补生物安全护栏，Google DeepMind 则把 Hassabis 抽回长期科学路线。

今日扫描 315 个追踪实体 · 27 个 fetcher · 1846 条原始帖 / 929 条候选。读法不是“又出了一个更强模型”，而是：能力在继续降价和普及，但最值钱的部分开始转向安全分级、工作流接入、上下文治理和可运营 agent。对你来说，机会不在复述模型榜单，而在把“普通人如何从聊天 AI 迁移到可交付系统”讲成一套认知升级路径。

🎯 源头 · Primary

📦 本日发布

  • OpenAI — GPT-5.6 Sol 在 ChatGPT 里升级准确性和一致性，同时 GPT-5.6 Luna 扩大到免费用户；官方 X 还强调 Free / Go 用户可以用 “Think” 做更多推理。
  • OpenAI — 把即将发布的 Astra 作为首个 critical cybersecurity 模型处理；Sam Altman 的口径是“不想只给少数人用强模型，但需要更长时间安全放开”。
  • Anthropic — 针对 Fable 5 的生物安全误拦和风险控制做更新；同时 AISI 报告 把 Claude Mythos 5 与 GPT-5.6 Sol 放进去护栏 cyber eval。
  • Google DeepMind — WeatherNext 在气旋预测上给出新的科学应用案例；Demis Hassabis 宣布转任 Chair / Chief Scientist，把日常产品执行交给 Koray。
  • Mistral — 发布 Shieldstral 3B，主打可本地部署的多模态内容安全评分，Apache 2.0 开源。
  • SGLang — v0.5.17 支持 Kimi K3 day-0 serving，覆盖 2.8T multimodal LatentMoE、1M context、MXFP4 checkpoint。
  • Sierra — 与 Plaid 合作，把银行账户连接直接嵌入企业客服 agent，从“对话”走向真实业务动作。

Harness / agent 工作台

  • Hermes — 继续把 agent 做成覆盖当前 app 的 HUD，不再要求用户先指定“我要操作哪个 app”。
  • OmniAgent — 组织 Multi-Agent Coding Meetup，信号是 multi-agent orchestration 正在从 demo 进入工程治理讨论。
  • OpenClaw stable — Reddit 上的 Extended-STABLE 讨论仍在发酵，说明用户开始关心 agent runtime 的稳定发布节奏，而不只是新功能。

  • a16z — “America debates Chinese AI while the rest of the world buys it”，这个判断和 Kimi / Qwen / DeepSeek 在中文平台的热度互相印证：低价、开放、可接入会先成为全球采用问题，而不只是国家叙事。
  • Sequoia / David Cahn — 把 AI 大厂竞争比作 strategy game：所有玩家都坐在同一张 AGI 棋盘上下注，重点不只是模型强弱，而是资本、分发、算力、生态的组合打法。
  • Conviction 相关 — DesignArena 6 个月从 5M 到 60M ARR，强化“AI 原生评测/设计基础设施”仍有垂直机会。
  • YC — Jared Friedman 用一句 “Claude Code has a Ballmer Peak” 捕捉了开发者真实体验：AI coding 工具已经强到改变习惯，但稳定性/节奏仍需要人类工作流兜底。
