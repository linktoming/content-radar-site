Agent 栈今天从“更聪明”转向“更可运营”：OpenAI 把 GPT-5.6 Sol 推到 14x Ultrafast

🔭 今日主线

Agent 栈今天从“更聪明”转向“更可运营”：OpenAI 把 GPT-5.6 Sol 推到 14x Ultrafast、ChatGPT 桌面开始记 Computer History，Anthropic 则把 Claude 的水印、风险报告、浏览器安全和跨端 session 摆到台面上。

今日扫描 319 个追踪实体 · 26 个抓取源 · 1133 条语义候选。主线不是单点模型参数，而是三个能力同时落地：更快的推理、更长的个人/组织记忆、更严的治理边界。对创作者和一人公司来说，这意味着“会写 prompt”继续贬值，“会把 AI 变成可控工作流”继续升值。

外部答案卷也在校准这个判断：TLDR/社区热榜把 Qwen3.8、Claude watermark、Anthropic risk report、开源模型状态推到前排；CN 侧则把 Claude Code、Codex、DeepSeek Harness、AI副业和 AI漫剧做成教程流量。技术前沿和市场需求正在同一件事上合流：把 agent 变成日常生产系统。

🎯 源头 · Primary

📦 本日发布
- OpenAI — GPT-5.6 Sol 的 Ultrafast mode 由 Cerebras 提供，最高 14x、750 output tokens/s，官方案例把安全调查从 1–2 小时压到 10–15 分钟。
- OpenAI — builder guide 明确把模型选择、Responses API、agent 成本效率放到创业公司工作流里，不是只讲 benchmark。
- Ollama — v0.32.13 继续更新本地模型运行基线。

模型 / 平台
- OpenAI — ChatGPT desktop 的 Computer History 能记住你跨 app / website 的活动，并提供 timeline、排除 app、暂停/清除等控制；这是 personal context 进入系统层。
- Anthropic — Claude text watermark 为 EU AI Act 做准备，强调不影响输出质量；同时发布 Risk Report，治理变成产品发布的一部分。
- Claude — Chrome side panel 与 desktop/web/mobile 共用同一个 Cowork session，browser agent 不再是孤岛。
- Google DeepMind — Gemini 3.7 Flash 面向 Pro/Ultra 开放，强调跨文件、邮件的多步推理。
- Alibaba Qwen — Qwen3.8-27B 上 Ollama，主打 agentic tasks 和本地 harness；这条和 Hugging Face 的“small models dominate real usage”互相印证。
- DeepSeek — V4-Pro / V4-Flash 强调 agent 升级、可调 reasoning effort、OpenAI Responses API 兼容，以及 Codex 一键配置。

Agent / DevTools
- Boris Cherny / ClaudeDevs — Claude Code desktop 增加 auto-continue，额度恢复后自动接着跑；这是长任务运维细节。
- Boris Cherny — Anthropic 内部试验让 Claude 承担 app 日常维护，包括 crash fuzzing、release note、issue triage，信号是“维护型 agent”开始成体系。
- Cursor — Cursor 正式并入 SpaceXAI，目标是让 Grok 成为“最有用的 AI agent”；coding tool 被吸进硬核执行组织。
- Lambda — 用 Claude Code 教 Gemma 打 Tetris，暴露出 agents 会钻漏洞、结果随环境漂移、long-horizon eval 很难复现。
