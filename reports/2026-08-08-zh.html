Agent 栈开始从“会做 demo”进入“可运营系统”：模型侧在降价和提速，工具侧在把 skills、browser、voice、code review

🔭 今日主线

Agent 栈开始从“会做 demo”进入“可运营系统”：模型侧在降价和提速，工具侧在把 skills、browser、voice、code review、observability 接进真实工作流。今日扫描 298 个一手/高信任源头 · 23 个 fetcher · 1,435 条报告候选。

外部答案卷也指向同一条线：TLDR AI 把 GPT-5.6 Luna default、Agent Plugins、AMD Taalas acquisition 放在头条；AINews 则把 GPT-5.6 Sol/Luna、Agent Plugins、Meta Muse Code、低价 frontier-ish 推理串成“质量 × 编排 × 成本”的新竞争面。今天不是单点模型新闻，而是可部署 AI 系统的四件事同时变厚：更便宜的模型、更会协作的 agent、更细的 safety 边界、更清晰的内容/一人公司需求。

🎯 源头 · Primary

📦 本日发布：
- Cline 连发 desktop / SDK / CLI / core 小版本，说明 coding agent 正在补多端和可编程接口，而不是只卷聊天体验。
- OpenCode v1.18.14 继续走轻量 coding harness 路线；它同日还把 DeepSeek Flash 用量翻倍，价格战已经传导到开发者工具。

模型与安全：
- OpenAI 更新 GPT-5.6 Sol，并把 GPT-5.6 Luna 扩到免费用户；OpenAI 还给 Plus/Pro 上了 reasoning effort slider，推理预算开始产品化。
- OpenAI 把即将到来的 Astra 按 Preparedness Framework 视为首个 cyber critical model；Greg Brockman 强调它在 agentic coding 和 cybersecurity 上进步明显。
- Anthropic 与 OpenAI 一起进入英国 AISI 的 cyber eval；Claude 同日把 Fable 5 生物安全误拒降约 85%，这是“更强但更少误杀”的产品信号。

成本与部署：
- Ollama 把 DeepSeek-V4-Flash-0731 设为 cloud 默认，主打 120+ output tps、零数据留存；Cline 说它已成 Cline 第一大模型，使用量 +40%、token 3x。
- vLLM 给 Kimi K3 提供 verified serving recipe；SGLang 合入腾讯 Hunyuan HPC-Ops kernel，推理栈继续从“能跑”转向“跑得省”。
- Reka 发布 RekaDaily-10k：10,312 小时第一人称家庭视频，physical AI 的数据战开始从合成环境回到真实世界。
- Cloudflare Kitesurf 把 agent-first browser 推到台前：browser 不再只是人用 UI，而是 agent runtime。
