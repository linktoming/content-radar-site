Agent 栈今天从“模型更强”转向“系统可运营”：OpenAI 给 Astra 加上 critical cyber 闸

🔭 今日主线

Agent 栈今天从“模型更强”转向“系统可运营”：OpenAI 给 Astra 加上 critical cyber 闸，Vercel / Cursor 推 Agent Plugins，Cursor Router、Warp Agent CLI、Sierra Voice Personas 都在补权限、路由、身份和体验层。

今日扫描 21 个来源通道 · 1413 条原始信号 · 715 条语义候选。AINews 把 Astra、Hugging Face incident、Managed Deep Agents、Claude Code 跨 session 消息放在同一条线上；TLDR 的头条也同时指向 GPT-5.6 Luna、Agent Plugins、GDM 重组、Meta Muse Code。主线不是单个模型发布，而是 agent 从聪明 demo 进入可部署、可审计、可分发的产品栈。

🎯 源头 · Primary

  • OpenAI〔S · model_maker〕— Astra 被列为首个 critical cyber model，OpenAI 说会放慢部分开发并加强 safeguards；Sam Altman 补充说目标仍是广泛开放，只是需要更安全地推出。
  • OpenAI — GPT-5.6 Sol 更新并扩大 GPT-5.6 Luna 免费访问，Plus/Pro 得到新版 Sol 和 reasoning slider，Free/Go 用户得到 Luna 与 Think 入口。
  • Vercel / Cursor〔A · dev_tools〕— Vercel 发布 Agent Plugins，Cursor 同步支持，核心是把 Skills 和 MCP server 打包成 agent 可发现、可加载的插件标准。
  • Cursor — Cursor Router 用真实产品交互做任务分类和模型路由，宣称 Auto Intelligence 在满意度超过 Fable 的同时降本 68%。
  • Warp — Warp Agent CLI 强调 agent orchestration UX、plan mode、bring-your-own-key、voice mode；这不是 IDE 功能，是本地 agent 操作台。
  • Sierra — Voice Personas 把“声音”和“人格”拆成可设计资产；Context Engine 则把企业知识转成 agent 可行动的决策上下文。
  • Google DeepMind — WeatherNext 用 AI 预测热带气旋路径和强度，官方说平均多给 24 小时准备时间。
  • Mistral — Shieldstral 是 3B 开源内容安全模型，可本地部署，Apache 2.0。
  • Moonshot / GitHub — Kimi K3 进入 GitHub Copilot，由 Fireworks 托管，继续把开源模型推向 agentic coding 的主战场。
  • Together AI — DeepSeek V4 Flash + test-suite verification 在 DeepSWE 上比 Luna 单跑多解题、单任务成本低 37%。
  • Hugging Face — ICML 2026 Reproduction Challenge 让 1200+ 参与者和 agents 复现/证伪 2000+ 篇论文，生成 13k repo 和约 3TB artifacts。
